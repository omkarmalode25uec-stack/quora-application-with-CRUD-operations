# Quora Clone

A simple Quora-style post application built using Node.js, Express.js and EJS.

## Features

- Create posts
- View all posts
- View individual posts
- Edit posts
- Delete posts
- Unique post IDs using UUID

## Technologies

- Node.js
- Express.js
- EJS
- UUID
- Method Override
- HTML/CSS

## How to Run

```bash
npm install
node index.js
